# Innovation Stress Test · 创新压力测试

输入至少包含研究命题、预期机制和拟用评价。先复述最强版本，不把未测想法伪装成已测事实。沿五条线攻击：替代解释、关键消融、结果不支持时的命题存亡、数据集/模型/场景变化的外部效度、审稿人最可能质疑的对照或统计问题。

对每个攻击点给“为何可能成立 → 最小区分实验 → 阳性/阴性解释 → 应保留或撤回的主张”，按可能性与损害排序。至少构造一个可以真正推翻核心命题的观察，并避免通过事后换指标、删 seed 或放宽 gate 保住结论。不能用抽象的‘更多实验’代替具体设计。

若创新依赖文献覆盖或正式指标，分别交给 `novelty-and-baseline-review` 或本插件的指标审计核验；需全面审查提案或稿件时用 `research-reviewer`。按需读 [ECG 领域档案](../../references/ecg-biometric-review.md)，不要把该领域风险套用到所有课题。
