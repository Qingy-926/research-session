# Perspectives selected as needed

This is the entry to the user's thinking prompts and optional project-failure rehearsal. Select modes for actual gaps; a complex task does not require every mode. Read only the corresponding references. When the goal and evidence are clear, proceed directly.

| Mode | Signals | Not applicable | Reference |
|---|---|---|---|
| Height: reconsider goals and route | Top-level path unclear, repeated manual work, or a request to redesign or automate | Local execution under a frozen objective | [Height](references/height.md) |
| Depth: strengthen reasoning | Evidence, method, or validation gaps; request for deeper rather than broader work | Mere feature expansion or ordinary polishing | [Depth](references/depth.md) |
| Breadth: cross-check blind spots | Risk of omissions across disciplines or stakeholders, or an explicit request for cross-checking | One well-defined issue with no cross-domain need | [Breadth](references/breadth.md) |
| Premortem: rehearse failure | Explicit request to assume failure, or a costly dependency/assumption that is still unverified | Routine low-impact work or an unchanged plan whose relevant risks are already covered | [Premortem](references/premortem.md) |

References preserve the user's original wording and provide bounded versions ready for use. Output should serve the actual task; show rewritten prompts only when requested. Apply conclusions to the active plan, check, or artifact, rather than merely listing what experts might do. Resolve significant undecided preferences using an applicable host-permitted question interface and continue after the answer; choosing a mode creates no approval gate.

Height can recommend restructuring a goal but does not replace an approved goal automatically. Depth neither expands scope nor invents evidence. Breadth defaults to the main model's multidisciplinary analysis and must not be presented as real experts or independent review. Premortem produces hypotheses and changes to the current plan, not evidence that failure occurred or permission to change research protocols. Actual delegation follows current user, host, and tool requirements; a template does not grant authorization.
