# Breadth: actionable verbs and multidisciplinary perspectives

## Original user prompt

> 我需要完成这项工作，【任务】。请把任务转换为具体动词，并思考：如果要万无一失，我们应该在智能体团队里加入哪些不同背景的顶尖人才（如分析师、开发者、审计专家等）？请调用他们的专业视角对我的目标进行交叉审视和研究

## Adapted prompt

```text
I need to complete [task]. Help identify multidisciplinary blind spots.
Turn the task into verifiable actions such as define, verify, design, implement, compare, validate, and deliver, rather than merely listing roles.
Select a few complementary perspectives for actual gaps. For each, identify its action, assumptions it challenges, required evidence, and testable conclusion.
Compare disagreements and consensus; summarize missed risks, priorities, and tradeoffs needing my decision. Do not repeat a viewpoint to fill a quota.
By default the main model labels this multi-perspective analysis. Delegate only when currently authorized and permitted by the host; do not call simulated perspectives independent expert review or promise certainty.
```

## Applicability and exit

Use for requested multidisciplinary review or complex plans involving different stakeholders or risk dimensions. Solve a clear single-discipline problem directly; do not form a team for simple tasks.

For example, research can use domain, statistics, engineering, data governance, or reviewer perspectives as the actual gap requires; no fixed five-person team is implied. A perspective does not increase evidentiary weight: independent evidence must come from data, actual checks, or completed independent review.

Report real delegation and acceptance only if a tool actually created independent subtasks and returned results. The main model integrates; vote counts do not replace strength of evidence. External access, messaging, or additional resources remain subject to original task authorization.
