# 示例：从问题走到公式

这是讲解片段，不是完整精读。材料为 Vaswani 等人的 *Attention Is All You Need*，arXiv:1706.03762v7，2023-08-02，§1、§2、§3.2.1 和 §6.2 表 3：https://arxiv.org/html/1706.03762v7 。

**原文与已有背景。** 论文指出，循环网络逐位置递推隐藏状态，这限制了单个训练样本中不同位置的并行计算；在此之前，注意力和自注意力已有应用（§1–2）。作者以此为背景提出 Transformer。

**可能的思考路径，属于推断。** 既然注意力已经能够按相关性读取其他位置的信息，一个自然的问题是：能否让位置之间直接交换信息，减少对逐位置递推的依赖？这只是依据论文背景作出的重建，并非已经证实的作者实际思路。

**核心直觉与教学例子。** 把当前位置的 query 想成一个查询，把其他位置的 key 想成索引，value 想成可读取的信息。查询与各 key 的相似程度决定从各 value 取多少信息。这个比喻用于理解，不表示模型真的在查询数据库。

**从公式看机制。** 论文 §3.2.1 将查询、键、值分别记为 $Q$、$K$、$V$，注意力计算为：

$$
\operatorname{Attention}(Q,K,V)
= \operatorname{softmax}\left(\frac{QK^{\mathsf T}}{\sqrt{d_k}}\right)V.
$$

先用 $QK^{\mathsf T}$ 计算匹配分数，再除以 $\sqrt{d_k}$ 调整分数尺度，通过 softmax 得到权重，最后对 $V$ 加权求和。$d_k$ 是查询和键向量的维度。

为什么要除以 $\sqrt{d_k}$？原文给出一个理想化假设：$q$ 和 $k$ 的各分量相互独立、均值为 0、方差为 1。此时：

$$
q \cdot k = \sum_{i=1}^{d_k}q_i k_i,
\qquad
\operatorname{Var}(q\cdot k)=d_k.
$$

方差可以粗略理解为数值波动大小。维度越大，点积分数的波动越大；将分数除以 $\sqrt{d_k}$ 后，在上述假设下方差变为 1。作者进一步**推测**，未经缩放的大分数可能让 softmax 落入梯度很小的区域。独立性与单位方差是解释所用假设，不是实际训练中必然成立的事实。

**问题 → 实验 → 答案。** 多头注意力是否有帮助？论文 §6.2 表 3 在英德翻译开发集 newstest2013 上比较不同头数，并相应改变每头维度以保持计算量；表中单头为 24.9 BLEU，8 头基准为 25.8 BLEU。这支持该实验设置下多头有帮助，不能据此推出所有任务中头数越多越好。

**仍不确定。** 以上片段没有核查其他数据集、训练种子或后续研究，因此不能据此判断该结论在所有设置下的稳定性。
