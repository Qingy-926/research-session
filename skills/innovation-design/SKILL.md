# Innovation Design · 论文创新设计

将 idea 拆成三层，**不**强行说成三个独立贡献：①研究问题（现象、对象、场景、空白）；②解决路径（为何这类干预有望消除空白，与最近邻方法差别）；③核心洞察（机制解释与适用条件）。逐层指出依据、推断和竞争解释。没有可定位文献时不得宣称首创。

完整方案必须联动 `novelty-and-baseline-review`、`innovation-stress-test`、`claim-driven-experiment-design` 和 `research-introduction` 的适用部分，并保留六项交付：三层结构；可证伪命题；反例/迁移压力测试；关键消融；最可能的审稿质疑；Introduction considerations 初稿。每个命题写“若结果为 X 则支持到哪一步，若非 X 则必须撤回什么”，避免实验无论如何都能解释成成功。

先有研究问题，再有可区分替代解释的实验；给出最低验证路径、资源上限和停止条件。与原论文忠实复现严格分线。跨技能传递信息使用 [研究简报](../../references/research-brief.md)，单次咨询可直接在回答中提供，无需新建文件。
