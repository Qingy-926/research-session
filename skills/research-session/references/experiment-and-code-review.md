# 有效实验与代码审查

## 工作顺序

1. **廉价事实优先**：核对真实数据、cohort、标签、排除规则、损失、checkpoint/选模、评分公式。用人工可算小样例、官方锚点和旧 checkpoint 只读重算，把口径效应与训练效应拆开。新的 test 评价仍需现行授权。
2. **建立基线**：先明确本步组合数 × 训练 seed × 人群 seed × 样本 seed，记录失败处理、时间/磁盘预算；低成本 smoke 检查可跑但必须标为 smoke，不取代正式矩阵。基线不是“原模型随便跑一次”。
3. **候选配对**：保留原论文损失/架构线；另立候选线。监督对比学习是否值得试，要看同协议、同数据、同选模下的开发证据及机制，不以“不是论文原方法”为由一概拒绝。
4. **一个变化回答一个问题**：协议修正先固定模型；训练方法比较先固定协议。不要一次替换预处理、cohort、损失、评分和选模，最后无法归因。
5. **分阶段扩大**：先验证候选可训练、损失有限、batch 有有效正负对、无 label 泄漏，再按批准矩阵执行配对比较。开发集达不到预设收益或不稳定时按停止规则停；不能因为看到了 test 更好就追着调。
6. **冻结后确认**：固定候选、选模、阈值、协议、统计单位，再做获批正式矩阵。选择算法本身若依赖 test/oracle，准确标明论文报告线而非部署线。

## 预注册最小表

| 字段 | 必填内容 |
|---|---|
| 本步目标 | 要分离的一个效应，具体可证伪预期 |
| 对比方法 | baseline 与每个候选的唯一差异 |
| 数据/协议/代码 | 内容指纹、真实路径、权威 commit、环境摘要 |
| 随机轴 | 每个轴含义、确切列表、组合数和总 run 数 |
| 配对/选模 | 共享的数据分配、训练 seed，val 选模规则及方向 |
| 指标 | 定义、split、full/fence、union/intersection、oracle/部署 |
| 资源 | 峰值显存、单 run 耗时、best/partial/优化器与临时文件空间 |
| 停止/失败 | 最大成本，非有限损失、失败 run、提前停止和续跑规则 |
| 决策 | 开发推进标准；正式 gate 另列，不能临时加宽 |

## 结构审查按因果路径，不按目录数量

- 数据与预处理：数据版本、采样率、导联、检测/切拍、归一化、缓存键与指纹；产出数据的源码是否已保留。
- 协议与随机性：排除集合是否真的应用，身份/录音/拍级泄漏，gallery 来源，seed 改了什么，重复样本和不足拍数的处理。
- 训练与选模：实际损失及权重、梯度流、SupCon 的 P×K/正样本数量、采样器、非有限 loss、优化器、scheduler、best checkpoint 与 val 指标选模方向。
- 评分与评估：张量维度、相似度符号、阈值方向、identity union/intersection、FPIR/FNIR 与 FAR/FRR 的事件空间、全池/子池、标准差来源。
- 编排与产物：命令实际参数、环境/Git/diff 绑定、失败退出码、完成 marker、partial 与 best 区别、每个 seed 独立目录，汇总是否排除失败/较差结果。

问题输出固定为“位置 → 复现方式 → 影响 → 最小修复 → 回归验证”。先修会改实验结论的问题，后考虑可读性/结构优化；修正历史结论时保留旧数字和适用协议，不覆盖成新口径。

## 跨 CLI 交接

一个状态文件，记录：权威树/commit/dirty diff、协议 hash、数据 hash、执行状态、已完成与未完成 run、已授权下一步、待用户判断。其他 AI 的结论必须回到产物验证，避免多份长日志互相当证据。不固定要求多智能体或高推理档位。
