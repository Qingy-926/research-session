## §4 预注册

起草结构沿用已验证模板（六件套）：

**起草前置**：先按 reproduction-ladder.md 定位当前复现阶梯层级——新复现 / 新对照目标
必须从 L0 论文审计起步，歧义清单未清零不得进入协议阶段；判据门必须与噪声底相容，并按该文件
"噪声底"节的**双门判据**（分辨力门 + 效度门）校验，最小感兴趣效应预登记。

1. **动机与现状**：引总账编号，说明为什么现在做这个单变量；
2. **冻结项**：数据 / 协议 / 口径 / seed 结构逐项列哈希或精确取值；
3. **输入哈希门**：启动前校验的输入 sha256 清单 + marker 语义（只在 rc=0 后写，fail-closed）；
4. **判据出数前写死**：门阈值 + 每种结果对应的动作（含灰区/HOLD 分支），并给出门阈值依据；
5. **诚实边界**：不得声称什么，措辞边界逐条写死；
6. **修正登记（§10）**：出数前的任何修正当场登记，写明"无任何结果数据产生过"。

可选：插件 `freeze-protocol` 把判据绑定 SHA-256（见 plugin-invocation.md）。
**预注册批准前触发复核点 1**（§6）。
