# 按缺证推进检索与正文核查

用于需要新增外部事实、查新、比较方法或核验科学主张的任务。已有充分材料的局部解释直接回答；不把每个问题都展开为完整文献综述。检索工具由当前宿主提供，本插件不内置检索服务或全文数据库。

## 先把问题变成可查的缺口

从当前问题提取待判断主张、研究对象、任务、数据/划分、比较方法、指标与时间范围。只列会改变结论的缺证点，例如最近邻工作、共同协议、反例或正文细节；直接复用项目已有证据，不另起重复表单。

明确已有授权中的时间、工具调用、全文访问和上下文预算。没有额度信息时先做一个有界小轮并报告实际消耗，扩大范围或付费另按宿主授权。预算是上限，不是应耗尽的指标；不因某个次数未用完继续搜索。

## 一个可回退的检索闭环

1. 用任务词、方法别名与关键条件做初检，记录问题、检索式、日期、数据库/工具和覆盖限制。元数据核身份，摘要只用于相关性筛选。
2. 选直接回答关键缺口的核心原文，核作者、年份、版本、DOI/arXiv/正式出处。会议版、预印本与重复数据库记录按论文归并，保留版本差异；同一论文的不同证据片段可以分别保留。
3. 对决定结论的核心工作向后读参考文献，向前找后续引用；前向工具不可用时明确缺口，并用标题/关键主张检索作有限替代，不声称完成引文追踪。
4. 主动查最近邻、相反结果、否定结果、复现失败与替代解释；改变关键词和任务边界以检查初检偏差。查到不同结论先核协议，不按票数裁决。
5. 读对应正文、附录、图表或官方代码；把发现映射回尚缺证据。只有能改变判断的缺口才触发下一轮。新线索可改变查询，不自动改变用户研究目标或实验协议。

## 保留可回查的证据

每个关键片段至少保留来源身份/版本、原文位置和访问级别；结果比较还需对象、数据与划分、方法/对照、指标及限制。可复用已有笔记或 sources JSON。需要独立回查时保留原件路径/URL和哈希，不把摘要笔记当作原文。

- `full_text`：已取得全文，但仍注明实际核读的章节/页码；取得全文不等于已读完整篇。
- `abstract` / `snippet`：只能支持该可见范围；方法细节、表格结果和局限仍待正文核查。
- 无法访问：保留精确待查项及其对结论的影响。不得用模型记忆补成“已核验”。

只把与本次问题有关的原文、必要上下文及定位送进模型；优先保留反证和条件差异，删除重复摘录。长文按问题分段读取，不无差别塞全文。需要批量组装时可用 `scripts/evidence_context.py`；它仅核本地摘录绑定、定位字段和字符预算，不能证明摘要无偏或证据支持了结论。

## 何时停止

检查已覆盖哪些关键缺口、仍缺什么及继续检索是否可能改变判断。关键主张已有可定位的直接证据、最近邻和反证路径已检查、当前范围内新增检索不再改变判断时可以停止；预算耗尽、来源不可达或工具失效也可停止，但须收窄结论并列未解决项。

论文数、搜索次数、未检出、重复出现和自报置信度都不能单独证明检索充分。报告“在所列范围内未检出”，不报告“不存在”。把新的待验证假设交回既有预注册与授权流程，不自动启动实验。
