## §1 证据读取顺序（依赖项目状态的任务）

项目接续、协议设计、执行、正式结果登记与定稿核查按本节读取。对已提供文本的局部润色走写作参考，只核查受影响内容，不以建接续卡、Git 对账或训练材料作为措辞修改前置。课程报告不属于本技能，按普通写作处理。

按本次任务读取必要证据；缺口按 §8 限制依赖步骤，不阻塞无依赖的分析。分级读区：热层（接续卡）先读，温层按下需下钻，不一次通读（三层路由见 `session-continuity.md`）。

1. 项目 `README.md` 状态板顶部的**接续卡**（目标15行/4KiB，保留本项目已有结构；必要字段和读取方式见 [接续参考](session-continuity.md)）；
2. **对账开场**：卡片 vs `git log --oneline -10` + `git status --short`、总账末条 vs
   卡片指针、产物目录存在性——漂移以产物为准修卡并报告；对账通过才继续依赖该状态的工作；
3. 状态板本体（权威数字来源行、进行中、下一步、待裁决区）——开工模式必读，其余模式按需；
4. `科研结果总账.md` **最近 1–3 条**（A*/G* 编号；只读文件尾部，不通读）；
5. 现行预注册：`00-立项/` 中最近仍未收口的预注册及其判据、硬门、诚实边界；
6. （可选）插件体检：`repro_governance.py status`（见 plugin-invocation.md）。

既有数据、不新增训练、不改协议/seed/选参/预算的探索性分析：直接执行并登记，标 `exploratory`，不进确认性判词；升级为确认性须新预注册。

## §3 开工：四件事汇报

按 §1 核对后简述以下事项；仅了解现状时给建议，已明确授权接续执行时继续，不为认领再求一次批准：

1. **权威数字**：状态板顶表数字 + 出处（总账编号）；
2. **在飞事项**：状态板"进行中"每条的当前状态（**以产物文件为准**，不以叙述为准）；
3. **下一步建议**：从状态板"下一步"按优先级给出建议认领项，说明理由；
4. **待裁决点**：凡标记"待用户裁决"的逐条列出，附各自选项与代价。

## §5 收尾：一次性登记清扫

结果出来后**一次**按序完成（取代旧的"多处分散登记"）：

1. **数字回溯**：每个要登记的数字都能指到原始 JSON/日志的具体字段；回溯不了 → 停，不登记；
2. **总账**：顺延编号（A*/G*），字段表式；含判定、诚实边界、产物（含缺陷注记）、证据层级；
3. **README 状态板**：只改"状态 / 进行中 / 下一步"三处 + 权威数字来源行；其余不动；
4. **04-验证**：若有验证文档，按当前宿主要求的时区记录证据时间，名称含日期与主题，不把固定+0800当作各端时区；
5. **git**：仅获提交授权时只 add 文档类改动（预注册 / README 等），不 add 大产物（runs/、checkpoint、数据）；提交信息说明登记了什么；总账等仓库外文件不涉及提交。
6. **复盘**（里程碑 / 项目收口）：把新约束写成"改哪行、改成什么、为什么" → 备份 → 向用户登记理由 → **批准后才落盘**，技能版本号 +1；不做运行时自我改写。

7. **刷新接续卡**：按 [接续参考](session-continuity.md)沿项目已有结构，只在状态、授权或下一步有实质变化时滚动替换对应字段；实际Git/进程/产物事实从工具取得，不凭记忆。
   不强制八字段模板、不每次追加冷区索引；有沿革价值的信息留所属证据。里程碑和异常中断需要接续时及时更新，纯解释无变化不写。

长任务纪律不变：每达里程碑把产物取回本地；链路做成可断点续跑；以产物文件为准。

## §8 fail-closed 行为表

| 情形 | 行为 |
|---|---|
| README 无状态板 / 读不到 | 报告缺口，暂停依赖该状态的执行；仍可做无依赖的授权内分析，不用旧会话记忆顶替事实 |
| 数字无法回溯到产物 | 不登记；先补产物或降级表述 |
| 插件 exit 2（缺证） | 如实转述 failures，停止依赖缺失证据的执行、登记和定稿；继续无依赖的授权内诊断、指标复算和草稿，不自行放宽门或自动重跑 |
| README 记载出数复核通过，但原始结果或依赖已变化 | 从 README 定位回执、输入清单和原件，用本技能的只读预检核绑定；旧回执仅作历史，不继承通过，不登记、不定稿、不自动重跑或重送；保留原件并继续授权内复算、定位缺证 |
| 预注册硬门未过 | 不执行后续步骤；先修输入或立修正案 |
| git 不可用 / 未提交 | 产物照写，标注"未提交" |
| "接近完成"但到达时限 | 到点即停，如实报告进度（用户硬边界） |
| 自主链遇未预注册情形 / 门未过 | 停：按 autonomy-bounds.md 边界表处理；门只能按预注册分支执行，不修改 |
| 同一问题连续两次失败且无新证据 | 停（patience 停机，见 autonomy-bounds.md），如实汇报并按宿主规则写 lessons，不硬耗 |
