# 让主张与外部证据相匹配

用于综合论文、比较方法、判断创新或审查过强结论。复用已有稿件、证据表和项目记录，优先检查决定结论的主张；不要求每句话另填新表。此流程不是模型能力认证，也不替代科研独立复核门。

## 区分信息类型和支持范围

写清哪些是原文可核事实、作者给出的解释、基于多项证据的模型推断、尚待验证假设。作者的因果解释不能直接写成已证机制；模型推断应列依据与仍未排除的解释，不能只加“推测”二字后继续强断言。

对每个关键主张检查：

1. 引文指向哪一段原文、表格或代码？原文是否真正支持这项主张的对象、方向、数值和范围？只有元数据/引文 ID 对上不能算支持；部分支持就拆分或收窄主张。
2. 不同结果是否使用相同任务、样本/统计单位、划分、训练与调参预算、指标定义和测试选择？不能直接比较时分别陈述，不编造共同排名或效应。
3. 观察到较高指标能排除哪些替代解释？数据、计算、监督、实现与评估选择可能共同变化。性能优势不自动推出机制、可迁移性、创新性或普遍优势。
4. 最近邻或反证能否推翻当前解释？优先补读能区分争议的原文、代码或重新计算；验证设计与已执行结果分开。

数字沿用既有来源/口径绑定；`claim_citation_guard.py` 与 `evidence_context.py` 只能做机械检查，不能认证蕴含、因果、查新或科研结论。不要把输出的 `verified` 字段当作独立核验。

## 反证驱动的复核

复核意见指出具体遗漏来源、替代解释、协议/统计问题或超出证据的句子，并说明可改变判断的最小核查。能在已有授权内核查的，查原文、代码或计算后记录证据及结论变化；未解决就保留限制。

同一模型重复回答、多模型投票、模型自报置信度和“审稿人口吻”均不是质量证据。增加模型调用、付费服务或复核轮次须遵守原授权；本流程不新增第三轮，也不重置 review_id。

## 读完整篇结论再交付

逐句引用正确仍可能组合成错误结论。复查来源是否混了同名实体、不同论文版本、数据集、实验组、时间点或协议；摘要、正文和最终结论的范围是否一致；是否把若干局部观察合并成未经验证的总体或因果主张。

遇到矛盾，先尝试定位条件差异或来源错误；不能解决就并列证据和替代解释，明确暂缓哪项判断。不要用“总体而言”掩盖反例，也不要为保留判断而拒绝已有证据能回答的较窄问题。

正式科研登记、实验执行和对外定稿仍走原三个独立复核点；普通阅读和局部文字编辑不因此新增送审门。
