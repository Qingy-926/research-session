# 研究简报（跨插件最小接口）

单次咨询可以直接在回答中表达，勿强制新建文件。需要传递时使用以下字段；已有项目状态板/预注册/原始 JSON 是事实来源，简报只是索引。

| 字段 | 填写规则 |
|---|---|
| research_question | 对象、场景、可回答的研究问题 |
| claims | 每项主张与状态：已测、推断、待测、已被反驳 |
| evidence | 原文或项目产物的路径/定位；数字标数据集、协议、split、指标、seed、选择方法 |
| applicability | 人群、数据、模型、威胁模型及适用边界 |
| unresolved | 未决语义、证据缺口与需要谁裁决 |
| next_tests | 命题、替代解释、最小区分实验与失败分支 |

不得因简报与原始产物冲突而覆盖原始产物。复现插件要复核事实时直接读取原件、冻结协议和代码。
