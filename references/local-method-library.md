# 通用判断方法候选（合成示例）

这些是用于方法路由的**合成判断场景**。使用前读取当前项目的有效总账和验证记录；示例不包含也不移植任何真实项目的数字、门槛或结论。

## 1. 阴性判据与机制证据分别处理

- 情境：方法改进预注册门槛未过，但部分机制诊断仍有独立证据。
- 判断问题：失败的是方法有效性、适用范围，还是机制解释中的某一环？各自的证据和门槛是什么？
- 做法：按预先定义的 gate 关闭失败主张；保留仅被实际结果支持的机制表述，并明确执行偏离和探索性等级。
- 来源：合成场景；实际判断须引用当前项目的有效总账与验证记录。
- 边界：仅为判读纪律，不意味着所有阴性实验都有可发表机制结论；该项目结论以最新有效总账为准。

## 2. 出数后的读出层需要可独立重算

- 情境：训练、数据和协议仍可复核，但统计读出或汇总归因有误。
- 判断问题：错误首次发生在原始训练/评估、结果计算、分桶汇总，还是门槛判定？
- 做法：保留原件，独立重算受影响层，再逐条撤回或收窄旧表述；不把时间相近的其他版本数字混排。
- 来源：合成场景；实际更正须回到当前项目的原始产物和更正表。
- 边界：不能仅凭状态板断言代码缺陷或统计显著性，须回原始产物和更正表核对。
