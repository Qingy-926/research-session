# 检索、证据与科研判断

5.1.0 在原精读、查新、审稿入口中加入两份按需参考：
[检索与正文证据](../skills/research-session/references/retrieval-evidence.md)与
[主张与证据](../skills/research-session/references/claim-evidence.md)。
它们使用已有项目记录和工具，不新增模型服务、全文库或科研批准门。
只有少量素材的局部问答无需展开完整综述。

## 可用流程与能力边界

围绕关键缺证初检，核核心原文，按需追参考文献与后续引用，补近邻、反例及否定结果；
把每轮发现映射回待判断主张，再决定下一轮或带限制停止。搜索次数和论文数不是充分性证据。
工具缺失、全文不可得、仅摘要或片段、未执行的前向追踪必须明确说明。

关键摘录保留来源、版本、位置、访问级别与必要上下文。比较时对齐任务、数据/划分、训练和调参预算、指标及统计单位；
分别标记原文事实、作者解释、模型推断与假设。检查反证、替代解释以及整篇结论是否混用实体、数据集或协议。
这些是可检查的工作方法，语义判断仍依赖模型或人工，不能由机械字段认证。

## 本地摘录组装

复用 `claim_citation_guard.py` 的 JSON 列表或 `{"sources": [...]}`，为选中的行补充 `locator`、`access`。
以下是合成的最小例子，假定 `paper.txt` 含有相同原文；`verified` 是调用者的声明，不是工具授予的事实认证。

```json
{
  "sources": [
    {
      "id": "source-a",
      "verified": true,
      "path": "paper.txt",
      "quote": "The result is limited to the evaluated setting.",
      "locator": "Section 4, paragraph 2",
      "access": "full_text"
    }
  ]
}
```

从实际加载的技能目录调用：

```bash
python -B "$RS_SKILL_ROOT/scripts/evidence_context.py" \
  --sources sources.json --id source-a --max-chars 16000
```

相对 `path` 基于 sources 文件所在目录。支持 `full_text`、`abstract`、`snippet`，不会把后两者升级为全文。
来源 ID 保留 Unicode，但不接受首尾空白、方括号或控制字符，保证生成的引用标记可被现有守卫识别。
可选 `source_sha256` 绑定文件字节。工具只读 UTF-8 文件，以空白规范化核摘录是否出现；
定位字段存在不等于页码真实、语义蕴含成立或来源可靠。
重复的同文件同摘录标为 `duplicates`；不把一篇论文内的不同片段合并。
超预算片段不截断，列入 `omitted`，`ok=false`、exit 2；应收窄所选材料或按已有授权调整预算。
预算限制的是输出 `context` 字符数，JSON 元数据另计。

## 设计依据

- [PaperQA2](https://storage.googleapis.com/fh-public/paperqa/Language_Agents_Science.pdf)：证据筛选、检索迭代与引文追踪提供设计动机；其专用工具、评测与人类比较结果不等于本插件收益。
- [Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/)：所测模型在受控长上下文任务中存在证据位置影响；不能推出通用字符阈值或摘要总是优于原文。
- [ALCE](https://aclanthology.org/2023.emnlp-main.398/)与[FActScore](https://aclanthology.org/2023.emnlp-main.741/)：分别关注引文支持和来源相对的原子事实精确率；都不能单独证明科学机制或检索充分。
- [内在自纠错研究](https://arxiv.org/abs/2310.01798)：无外部反馈的推理修订有局限；不等于有原文、计算和执行反馈的核查无效。
- [实体歧义研究](https://aclanthology.org/2024.findings-acl.160/)：独立可支持的事实可能混合不同实体；将检查扩展到科学协议的一致性是工程假设，尚非该论文已验证结论。

## 怎样评价质量

冻结真实任务和原文版本，保留未用于规则设计的任务；同模型、相同工具和材料预算比较现行基线、仅检索、仅判断、两者均改。
分别记录关键来源覆盖、引文身份与支持范围、矛盾/替代解释、判断错误、适当保留判断、完整结论一致性和时间/成本。
覆盖率只对事先登记的范围有意义，模型辅助评分需抽查原文并注明缺少人工金标准。
本轮本地试验仅为两个真实问题、封闭语料、每条件一次的可行性检查，不足以估计稳定增益、开放网络召回或普遍科研能力。
单元测试、合成黄金用例、模型间一致和自报置信度均不替代真实科研质量证据；持平和失败如实保留。

## 5.1.0 实际观察

两个保留问题分别检查 DINOv2 的普遍替代/免微调主张，以及 DLinear 的注意力无用主张。
每题四条件、各运行一次，同一请求模型和封闭原文目录，每题来源访问上限 28000 字符。
独立模型辅助盲评后抽查原文；没有人工金标准。八份回答的核心判断均为 2/2，未观察到判断分数提升。

| 条件 | 视觉题必需来源覆盖 | 视觉题引文支持 | 预测题主张支持 | 预测题引文定位 |
|---|---|---|---|---|
| 5.0.0 基线 | 2/3 | 5/6 | 17/17 | 5/5 |
| 只改检索 | 3/3 | 7/7 | 24/24 | 7/7 |
| 只改判断 | 2/3 | 5/5 | 16/16 | 4/5 |
| 两者均改 | 3/3 | 6/6 | 20/20 | 5/5 |

支持性分母为实际列出的被引陈述；预测题进一步拆为原子主张，两个任务不能合并为一个准确率。
视觉题覆盖改善仅表示查阅了预先指定的 CLIP 原文片段；部分近邻仅查第一页，不代表完整精读。
保留问题包括基线一处不完整定位、只改判断条件一处正文未配定位及预测题一处页码错误。
组合条件的列出引文均通过，未出现关键错误，但无开放检索、前向引用追踪或普遍收益证明。
四条件完成两题的自报耗时依次为 206、176、167、341 秒；不是受控性能测试，没有 token 或费用测量。
保留流程用于证据可回查与边界约束；不能据本轮结果声称模型科研判断能力已提高。
